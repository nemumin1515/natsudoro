# ナッツ強盗をさがせ！— PeerJS版 v3

親機PCが部屋を作り、スマホやPCがQRコードから参加するゲームです。
LAN版（step5-no-node）との違いは **通信方式** です。

## v3 の変更点（v2から）

- **あそびかた（チュートリアル）を追加**：案内役「くらし係のモモ」が、10ページでおうちのくらしのきまりを説明します（おさんぽ・空腹度・丸太→ごはん・回し車と停電・強盗・会議・特別な係・勝ち負け・ボタン早見表）。初めて開いたときに自動で表示され、あとからはホーム・待機部屋・ゲーム中の「📖 あそびかた」ボタンで開けます。スワイプ・矢印キーでページ送り、Escで閉じます。
- **QRコードから参加した人には「親機として部屋を作る」を出さない**：URLに部屋番号（`?room=`）が付いているときは、参加フォームだけを表示します。

## v2 の変更点（v1から）

- **通信が切れても試合を止めない**：NPC以外の人が1人でも接続中なら、そのまま続きます。切れた人のキャラクターはその場に残ります（名前の前に 📴 が付きます）。残ったキャラクターは、ナッツを奪われたり、会議で投票されたりします。本人が戻れば、同じキャラクターで再開できます。人が全員切断したときだけ、従来どおり一時停止します（30秒戻らなければ勝敗なしで終了）。
- **スマホは縦向きでも横向きでも参加できる**：縦向きでは縦長の範囲を表示します（見える横幅は狭くなります）。
- **指への追従を改善**：画面のどこを押しても、指の方向へ動きます。自分のキャラクターは通信の返事を待たずにすぐ動き、親機の位置で少しずつ補正します。指の真下に来ると止まります。

| | LAN版（step5） | PeerJS版（この v3） |
|---|---|---|
| 通信 | 親機PCのPowerShell中継 | PeerJS / WebRTC（端末どうしが直接つながる） |
| インターネット | 不要 | **必要** |
| 同じWi-Fi | 必要 | 不要（携帯回線のスマホも参加できる見込み） |
| 起動 | `.bat` で黒い画面を起動 | Webページを開くだけ |

## 公開のしかた（GitHub Pages）

1. このフォルダーの中身をそのままGitHubのリポジトリに入れます（`index.html` がいちばん上に来るように）。
2. リポジトリの Settings → Pages で公開します。
3. `https://ユーザー名.github.io/リポジトリ名/` を開くと、ゲーム画面（`public/`）へ移動します。

※ WebRTCはHTTPSのページでしか動きません。GitHub PagesはHTTPSなので、そのままで大丈夫です。
※ PCのフォルダーから `public/index.html` を直接ダブルクリックすると、1人用の `play-offline.html` が開きます（LAN版と同じ動作です）。

## 遊び方

1. 親機PCで公開URLを開き、「親機として部屋を作る」を押します（URLに `?host=1` が付きます）。
2. 部屋番号とQRコードが表示されます。
3. スマホでQRコードを読み取ります。部屋番号を手で入力しても参加できます。
4. 全員が「準備OK」にすると開始できます。

遊んでいる間は、**親機PCのブラウザーのタブを閉じたり再読み込みしたりしないでください**。ゲーム本体は親機のタブの中で動いています。

## 通信のしくみ

- 親機は `nuts-robber-v3-部屋番号` というIDで、PeerJSの無料公開サーバー（0.peerjs.com）に登録します。
- スマホはこのIDを目印に親機を探し、見つかったあとは親機と直接データをやり取りします。
- 直接つながらないネットワークでは、PeerJSが用意している中継サーバー（TURN）を自動で使います。
- 2秒ごとに生存確認を送り、9秒応答がなければ切断とみなします。切断された人は自動でつなぎ直します。試合中はほかの人が接続していれば待たずに続行します。

設定は `public/peer-config.js` で変えられます（ふだんは変更不要です）。

- `publicUrl`：QRコードに入れるURL。空欄なら、今開いているページのURLを使います。
- `server`：自分でPeerJSサーバーを立てた場合の接続先。
- `idPrefix`：PeerIDの頭に付ける文字。

## 注意点

- PeerJSの公開サーバーは無料サービスです。止まっている間は新しく参加できません（すでにつながっている人はそのまま遊べます）。
- 学校や会社のネットワークでは、WebRTCが制限されていてつながらない場合があります。
- 親機のタブを再読み込みすると、部屋番号が変わります。参加者は新しいQRコードを読み直してください。
- 親機のタブを裏に回すと、ブラウザーの省電力機能でゲームの動きが遅くなることがあります。親機の画面は前に出しておいてください（LAN版と同じです）。

## 開発者向け：自前サーバーでのテスト

`npm i peer` でPeerJSサーバーを立て、URLに `&peerHost=127.0.0.1&peerPort=9000&peerSecure=0` を付けると、公開サーバーの代わりに使えます。

## 遊べること

- 最大11人、12キャラクターから重複なしで選択
- 「ふかふか寝床」「丸太食堂」「天空の雲庭」の3ステージ
- 各ステージの上下中央にある出入口から、別のステージへ往復可能
- 天空の雲庭では、中央の大きな雲山や周囲の高い雲花壇は通行不可
- 通常開始は1〜11人・参加者全員の準備OKが必要
- 役職は本人の画面だけに表示
- 4人以上では、キャラクター側の「探偵」と犯人側の「道化師」が1人ずつ登場
- 5人以上では、キャラクター側の「料理人」が1人登場
- 探偵は1試合に1回、近くの相手の犯人可能性を「高（3）・中（2）・低（1）」で調査
- 道化師は通常の犯人行動に加え、1試合に1回、近くの相手の名前と姿へ20秒間変身
- 料理人は1試合に1回、現在地に追加のご飯を置ける（誰かが食べるまで残る）
- 変身中でも会議では本来の名前と姿を表示
- 犯人数は人とNPCの合計5人につき1人（5〜9人で1人、10〜11人で2人）。4人以下も遊べるよう、最低1人。テスト開始でも同じ人数になり、親機が犯人側になる
- ナッツ強奪、花柄・葉っぱ柄マットの通気口、停電
- ゲーム開始から30秒間はナッツを奪えない（NPCの犯人と1人用の練習画面も同じ）。「奪う」の残り時間を表示し、30秒後は通常どおり利用可能
- 通気口はすべてつながっており、一覧から移動先を選択
- 空腹、各ステージに1つずつ出現し続ける通常のご飯、丸太、回し車と電力切れによる停電
- 通常のご飯を食べると、同じステージ内の別の場所に新しいご飯が出現
- ナッツを奪われた人はほかの人から見えず、会議に参加できない
- ナッツを奪われた人は回し車で停電を直せる
- ナッツを持つ人だけが会議を開き、投票できる
- 会議の画面上部で、別のステージにいる人やNPCを含め、会議に参加できる全員から通報先を選択できる。11人いる場合は候補一覧の中を上下にスクロール
- 会議中は参加者が「自分のいたステージと場所」を1回証言でき、全員の画面に共有される
- 証言は本人が選ぶ自己申告。ナッツを失った人も証言一覧は読めるが、投稿と投票はできない
- 最多票が1人なら、人間の手でキャラクターをつまみ出す演出
- 同数票または「誰も追放しない」が最多なら追放なし
- 会議で犯人を全員通報して追放するとキャラクターチームの勝利
- ナッツを失うか追放されて、ナッツ強盗以外の人が全員ゲームからいなくなるとナッツ強盗の勝利（1人で開始した試合は開始直後に終了しない）
- ナッツを持つ人が犯人自身も含めて残り3人以下になったら犯人の勝利（試合開始時から3人以下の場合は、ナッツを失うか追放が起きてから判定）。または、残った全員の空腹度が100で犯人の勝利
- 通信が切れた人のキャラクターはその場に残り、試合は続行（人が全員切断したときだけ一時停止）

## NPCの動き

- 親機だけが、試合開始前にNPCを追加・削除できます。NPCは空いているキャラクターを1つ使い、自動で準備OKになります。人とNPCを合わせて最大11人です。親機またはスマホから人が1人以上参加してください。
- NPCも参加者と同じ移動・障害物・空腹・食事・ナッツ・役職・追放・勝利条件で扱われます。犯人になったNPCは近くのナッツを奪い、探偵や道化師、料理人になったNPCはそれぞれの能力を使えます。
- 普段はステージを歩き回ります。空腹度が50以上になると丸太をかじり、その後でご飯を食べます。停電時はナッツを奪われたNPCも回し車に向かい、電気を回復します。
- NPCは自分が長くいた「ステージ・場所」を会議で証言し、その内容が全員の画面に表示されます。会議が始まるまでに近くで目撃した人の場所も覚えています。
- NPCは、相手の証言と実際に目撃した場所が一致すればその相手には投票しません。目撃していない場所を証言した参加者が複数いれば、ランダムに1人選んで投票します。未目撃は嘘の証明ではなく、NPCが確認できなかったという意味です。候補がいないときは投票せず、会議の時間が来るまで待ちます。
- 料理人のNPCは空腹度が100になり、周囲に食べられるご飯がないときだけ、1試合1回のご飯を現在地に置きます。
- 道化師のNPCは、周囲に誰もいないとき、参加中のほかの人を1人選んで20秒間変身します（1試合1回）。
- 探偵のNPCは近くの人を1試合1回調査します。結果は低（1）・中（2）・高（3）で、高（3）なら会議を開いて調査した本人へ投票します。会議がまだ開けないときは、開けるまで調査結果を覚えます。

## 通信の安定化

- 会議中に通信が切れた場合、投票は接続中の人だけで締め切る（切れた人も投票先には残る）
- 参加端末の通信が切れたとき、自動でつなぎ直す（2秒ごとの生存確認で検知）
- 親機が完全に再起動されて以前の部屋が消えた場合、新しいQRコードを読む案内を表示
- Windows起動ファイル、QR中継、主要ゲームルールをまとめて確認

## 少人数テスト

通常ゲームも人とNPCを合わせて1〜11人で開始できます。1〜3人では特殊役職は登場しません。4人以上で探偵と道化師、5人以上で料理人も登場します。「親機を犯人にしてテスト」を使うと、親機が必ずナッツ強盗側になり、回し車の電力は20秒で切れます。通常ゲームでは役職がランダムに決まります。

## QRコードが出ない場合

1. ZIPを「すべて展開」したフォルダーから起動したか確認します。
2. `QRでみんなと遊ぶ.bat` を開きます。`play-offline.html` にはQRコードは出ません。
3. 親機PCをWi-Fiにつないでから、もう一度起動します。
4. まだ動かない場合は、黒い画面に出た文章の写真を送ってください。

## 補足

この版はNode.js、npm、インターネット接続を使わずに起動できます。通信は親機PCの中だけで処理され、一般公開はされません。
